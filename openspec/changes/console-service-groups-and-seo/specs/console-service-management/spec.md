## MODIFIED Requirements

### Requirement: Экран управления сервисами проекта

Консоль SHALL предоставлять администратору проекта экран управления сервисами: список переключаемых сервисов платформы с текущим состоянием и переключателями. Ядровой сервис аутентификации MUST NOT быть доступен для выключения. Лицензирование MUST NOT предлагаться отдельным переключателем: его разделы включаются вместе с сервисом оплаты. Просмотр SHALL требовать право на просмотр проекта, переключение — право управления сервисами; оператору без права переключения переключатели SHALL быть недоступны.

#### Scenario: Администратор выбирает сервисы проекта

- WHEN администратор открывает экран управления сервисами
- THEN он видит переключаемые сервисы (контент, аналитика, оплата) с текущим состоянием и может включить или выключить каждый галочкой

#### Scenario: Ядровой сервис защищён

- WHEN администратор просматривает список сервисов
- THEN сервис аутентификации не предлагается к выключению

#### Scenario: Отдельного переключателя лицензирования нет

- WHEN администратор просматривает список сервисов
- THEN лицензирование отсутствует отдельной строкой, а его разделы появляются вместе с включением оплаты

#### Scenario: Оператор без права управления

- WHEN экран открывает оператор без права управления сервисами
- THEN состояние сервисов видно, но переключатели недоступны
