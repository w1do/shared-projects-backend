## MODIFIED Requirements

### Requirement: Группы меню собираются по сервисам платформы

Меню панели SHALL группировать разделы по сервисам платформы. Разделы сервиса `pay` SHALL собираться в одну группу «Оплата»: транзакции оплат, подписки, тарифные планы, тарифные планы лицензий, лицензии, организации, релизы. Разделы сервиса `content` SHALL собираться в одну группу «Контент»: блог, категории, ресёрч, инструкции, SEO, города. Каждая группа SHALL появляться в меню при включении своего сервиса и исчезать целиком при его выключении — без повторного входа оператора.

#### Scenario: Включение оплаты открывает группу

- WHEN администратор включает сервис `pay` на экране управления сервисами
- THEN в меню появляется группа «Оплата» со всеми её разделами, доступными оператору по правам

#### Scenario: Выключение контента закрывает группу

- WHEN администратор выключает сервис `content`
- THEN группа «Контент» исчезает из меню целиком, включая разделы SEO и городов

#### Scenario: Часть разделов группы закрыта правами

- WHEN сервис `pay` включён, а у оператора есть право только на просмотр лицензий
- THEN группа «Оплата» отображается и содержит только раздел лицензий

#### Scenario: Раздел городов закрыт правами

- WHEN сервис `content` включён, а у оператора нет права `content.cities.view`
- THEN группа «Контент» отображается без пункта «Города»
