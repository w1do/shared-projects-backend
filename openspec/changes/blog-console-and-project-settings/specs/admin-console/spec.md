## ADDED Requirements

### Requirement: Пагинация списков — общий механизм консоли

Разделы консоли со списками SHALL использовать единый механизм пагинации: текущая страница, размер страницы и подвал с переключением страниц. Поведение MUST быть одинаковым во всех разделах: смена фильтра или размера страницы SHALL возвращать оператора на первую страницу, а уменьшение числа записей MUST NOT оставлять его на несуществующей странице. Подключение пагинации к новому разделу MUST NOT требовать копии этой логики в разделе.

#### Scenario: Одинаковое поведение разделов

- **WHEN** оператор листает список в любом разделе с пагинацией
- **THEN** страницы переключаются одинаково, показаны номер текущей страницы и диапазон записей

#### Scenario: Фильтр возвращает на первую страницу

- **WHEN** оператор на третьей странице меняет фильтр списка
- **THEN** список показывает первую страницу отфильтрованных записей

#### Scenario: Записей стало меньше

- **WHEN** после удаления записей текущая страница выходит за пределы списка
- **THEN** оператор оказывается на последней существующей странице, а не на пустой

#### Scenario: Смена размера страницы

- **WHEN** оператор меняет размер страницы
- **THEN** список пересобирается с начала с новым размером
