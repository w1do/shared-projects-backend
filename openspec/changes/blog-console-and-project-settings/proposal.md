## Why

Раздел блогов и настройки проекта остались наполовину шаблонными. Ревизии подписаны голым `#10` — оператор не понимает, к чему откатывается, и не может убрать мусорные версии. Пост, собранный AI, нельзя пересобрать: правки идут руками. Закрепление поста сверху выбирается «первым из списка», а не решением оператора, и у закреплённой карточки не видно изображения. Предпросмотр статьи показывает вымышленного автора и узкую колонку вместо содержимого блоков. Раздел настроек «Основные» — до сих пор «Профиль магазина» из склада вёрстки: единица веса, адрес витрины в `localStorage`, валюты EUR/GBP/VND и часовые пояса Лос-Анджелеса, сохранение-заглушка без обращения к платформе.

## What Changes

- **Ревизии поста**: в списке версий показывается название материала на момент снимка и номер версии; ненужную ревизию можно удалить. Восстановление работает как прежде.
- **Пересборка поста через AI**: действие в форме поста заново собирает заголовок, содержимое (до 10 блоков) и SEO-поля по материалам базы знаний. Slug, категории, теги, изображения и статус остаются прежними. Прежняя версия уходит в ревизию — откат в один клик. Задача идёт в фоне с прогрессом.
- **Закрепление поста**: у поста появляется признак `is_featured`. Закреплённый пост в проекте один: закрепление нового снимает признак с прежнего. Консоль показывает его карточкой во всю ширину, **с изображением** — сейчас оно не отображается.
- **Предпросмотр статьи**: модальное окно собирает markdown всех блоков поста, растягивает содержимое на всю ширину окна и больше не показывает автора.
- **Пагинация**: состояние страницы и размера страницы выносится в общий переиспользуемый хук с общим компонентом подвала, вместо копии в каждом разделе.
- **Сайдбар**: переход в раздел на мобильном происходит сразу — анимация закрытия панели не задерживает показ уже загруженного раздела.
- **Настройки → Основные**: раздел переделывается под проект. Заголовок «Главные настройки сайта», описание «Настройки сайта, управление данными». Поля: название сайта, описание, тип проекта (блог / магазин / корпоративный сайт / лендинг), часовой пояс (российские), валюты (RUB, USD) и валюта по умолчанию, язык по умолчанию с перечнем языков, привязанных к проекту. Название и описание — это поля самого проекта (`projects.name`, `projects.description`), второго названия не заводим; остальное хранится в `spatie/laravel-settings` настройками проекта.
- **BREAKING (консоль)**: из «Основных» убираются поля склада вёрстки — единица веса, email поддержки, телефон, адрес витрины; сохранение-заглушка `saveSettingsMutation` и запись `storefront_live_url` в `localStorage` удаляются.

## Capabilities

### New Capabilities

- `console-project-settings`: раздел «Основные» в консоли — состав полей проекта, их источник (настройки проекта платформы) и поведение сохранения.

### Modified Capabilities

- `content-posts`: ревизии получают название и удаление; добавляются закрепление поста, пересборка через AI и правила предпросмотра статьи в консоли.
- `content-service`: Admin API постов получает признак закрепления с правилом единственности, удаление ревизии и запуск пересборки поста.
- `settings/site-preferences`: настройки проекта пополняются типом проекта и часовым поясом; язык по умолчанию ограничивается языками проекта, валюты — рублём и долларом.
- `admin-console`: пагинация списков становится общим механизмом консоли с одинаковым поведением во всех разделах.
- `console-navigation`: переключение раздела на мобильном не ждёт анимацию сайдбара.

## Impact

**Бэкенд**
- `packages/cms/content`: миграции `posts.is_featured`; `Post`, `UpsertPostDTO`, `PostDTO`, `UpsertPostRequest`, `PostController`; удаление ревизии (`DeleteRevisionHandler`, маршрут); пересборка поста (команда, handler, job, маршрут).
- `packages/cms/research`: `GeneratePostFromTopicHandler` разделяется на сборку черновика и пересборку существующего поста; `BackgroundTaskKind` получает вид задачи пересборки.
- `packages/cms/auth`: `SiteSettings` (spatie) получает `project_type` и `timezone`; `SiteSettingsDTO`, `UpdateSiteSettingsRequest`, ресурс и провижининг новых проектов; название и описание правятся существующим `PATCH projects/{project}`.
- Снимки контрактов: `posts-index`, `posts-show`, `posts-revisions`, `site-settings`; пересборка `openapi/openapi.json`.

**Консоль**
- `frontends/admin`: `PostLifecycleCard` (ревизии), форма поста (пересборка, закрепление), `blogs-featured`, `blog-preview-modal`, `next.config.ts` (`images.remotePatterns` для медиа платформы), общий хук пагинации и `DataTableFooter`, `AdminSidebar`, `settings/sections/GeneralSection` и `SiteLanguageSection`, реестр текстов консоли.
- Парность со складом: изменения в `components/app/**` переносятся в `frontends/source-admin` тем же коммитом; собственные компоненты консоли (диалоги, формы платформы) живут только в `admin`.

**Данные**
- `posts.is_featured` — новая колонка (default `false`), закреплённых постов до миграции нет.
- Настройки проекта пополняются двумя ключами группы `site`: `project_type` и `timezone`; существующие проекты получают значения по умолчанию — тип `blog`, часовой пояс `Europe/Moscow`.
