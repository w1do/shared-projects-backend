# ai-translation-fill

## Purpose

Заполняет недостающие локали — в словаре переводов и в переводимых полях — операцией перевода AI-пакета, помечая результат как автоперевод, чтобы оператор видел, что проверено человеком, а что машиной.

## ADDED Requirements

### Requirement: Автоперевод недостающих локалей

Платформа SHALL предоставлять операцию «перевести недостающее» для записей словаря и переводимых полей: значения исходной локали переводятся операцией перевода AI-контракта на локали проекта, у которых значения нет. Существующие значения MUST NOT перезаписываться. Операция SHALL выполняться в фоновой задаче.

#### Scenario: Заполнение недостающих локалей ключа

- **WHEN** у ключа есть `en`-значение, у проекта локали `en` и `ru`, и запущен автоперевод
- **THEN** появляется `ru`-значение перевода, `en` не изменяется

#### Scenario: Всё уже переведено

- **WHEN** у записи есть значения всех локалей проекта
- **THEN** операция ничего не меняет и не вызывает провайдера

### Requirement: Автоперевод помечен до подтверждения

Значение, созданное автопереводом, SHALL быть помечено как машинное. Пометка SHALL сниматься при ручном изменении или явном подтверждении значения. API словаря SHALL отдавать признак, чтобы панель могла отличать проверенные переводы.

#### Scenario: Пометка автоперевода

- **WHEN** значение локали создано автопереводом
- **THEN** запись отдаётся с признаком машинного перевода

#### Scenario: Ручная правка снимает пометку

- **WHEN** оператор изменяет автопереведённое значение
- **THEN** признак машинного перевода снимается

### Requirement: Отказ AI не портит переводы

Ошибка AI-операции SHALL оставлять записи без изменений и фиксироваться в журнале задачи; частично применённых переводов одной записи быть MUST NOT. Повторный запуск операции SHALL быть безопасен (идемпотентен по уже заполненным локалям).

#### Scenario: Провайдер отказал

- **WHEN** операция перевода завершилась ошибкой провайдера
- **THEN** значения записей не изменились, ошибка видна в журнале задач

#### Scenario: Повторный запуск

- **WHEN** автоперевод запускается повторно после частичного успеха
- **THEN** переводятся только оставшиеся недостающие локали
