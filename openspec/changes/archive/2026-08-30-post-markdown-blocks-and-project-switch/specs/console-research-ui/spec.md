## MODIFIED Requirements

### Requirement: Состояния раздела ресёрча единообразны

Раздел SHALL открываться сразу: до получения данных показывается сам раздел с его шапкой и элементами управления, а не промежуточный скелетон вместо содержимого. Пустой список SHALL показываться единым для консоли пустым состоянием с предложением действия, а ошибка платформы — уведомлением вёрстки. Отбор по состоянию исследования SHALL выполняться тем же элементом отбора, что и в остальных разделах, а не набором самостоятельных кнопок.

#### Scenario: Загрузка списка

- **WHEN** список исследований ещё загружается
- **THEN** раздел уже показан со своей шапкой и элементами управления, скелетон вместо содержимого не появляется

#### Scenario: Пустой раздел

- **WHEN** у проекта нет исследований
- **THEN** показано единое для консоли пустое состояние с действием запуска исследования

#### Scenario: Отбор по состоянию

- **WHEN** оператор отбирает исследования по состоянию
- **THEN** отбор выполняется штатным элементом отбора консоли
