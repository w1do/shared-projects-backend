## ADDED Requirements

### Requirement: Подключённые разделы открываются без промежуточного скелетона

Раздел, данные которого приходят из API платформы, SHALL отрисовываться сразу: оператор видит шапку раздела и его элементы управления, пока данные ещё загружаются. Промежуточный скелетон вместо содержимого раздела MUST NOT показываться. Разделы вёрстки на демо-данных этим требованием не затрагиваются.

#### Scenario: Раздел виден до прихода данных

- **WHEN** оператор открывает подключённый к платформе раздел, данные которого ещё загружаются
- **THEN** он сразу видит шапку раздела и элементы управления, а не скелетон вместо всего содержимого

#### Scenario: Данные подставляются без перерисовки раздела

- **WHEN** данные раздела пришли
- **THEN** они подставляются в уже показанный раздел, шапка и элементы управления не переоткрываются

#### Scenario: Пустой результат отличим от загрузки

- **WHEN** данные пришли и оказались пустыми
- **THEN** раздел показывает единое пустое состояние, а не остаётся в состоянии загрузки
