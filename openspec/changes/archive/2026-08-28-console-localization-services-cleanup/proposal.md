# Console: русские тексты, управление сервисами, чистка разделов

## Why

Консоль показывает оператору английские тексты шаблона Ætheria (все UI-строки — хардкод в JSX/lib, механизма локализации панели нет), хотя платформа уже имеет таблицу локализаций (словарь переводов с плоской выдачей по локали и `translations_version` в bootstrap) — она панелью не используется. Управление сервисами проекта реализовано на бэкенде (галочки content/analytics/pay), но экрана в консоли нет — администратор не может выбрать, какие сервисы нужны проекту, хотя сайдбар уже умеет скрывать разделы выключенных сервисов. Живые разделы при этом показывают нерелевантные фрагменты шаблона: карточки аналитики и долларовые колонки в категориях (всегда $0.00 — платформа этих данных не имеет), захардкоженные дельты KPI, демо-секции дашборда про e-commerce.

## What Changes

- **Русская локализация консоли через таблицу локализаций.** Все тексты видимых разделов панели, которые уже подключены к живым сервисам (каркас: сайдбар/топбар/логин/unauthorized; разделы: dashboard, blogs, categories, customers, team, settings + вкладка переводов; диалоги, тосты, пустые состояния, сообщения ошибок API и валидации форм) переводятся на русский. Механизм: реестр ключей `console.*` с русскими текстами по умолчанию + переопределение из словаря переводов проекта (существующий эндпоинт плоской выдачи `?locale=`), локаль — из `bootstrap.user.locale`, инвалидация кэша — по `bootstrap.translations_version` (оба поля появляются во фронтовом типе `PlatformBootstrap`).
- **Экран управления сервисами.** Новая вкладка «Сервисы» в Settings из существующих компонентов шаблона (`SettingsSection` + `SettingsToggleRow`): галочки для переключаемых сервисов (`content`, `analytics`, `pay`; `auth` — ядро, выключить нельзя), поверх готовых обёрток `projectServices.list/toggle`. После переключения bootstrap перечитывается и снапшот разделов обновляется — сайдбар и quick actions отражают состав сервисов без повторного входа.
- **Чистка категорий.** Убираются: блок карточек аналитики над таблицей (`CategoriesStats` целиком), долларовые колонки таблицы (`Revenue`, `Growth YoY`), блок «Sales Revenue» карточной сетки, обязательные поля `Revenue ($)`/`Growth YoY (%)` формы (и из zod-схемы), долларовые блоки PDF-отчёта и превью. Описание раздела — без «sales metrics».
- **Релевантные данные в живых разделах из существующих компонентов.** Для каждого живого раздела — только уместная разделу информация из компонентов, которые уже есть в шаблоне: дашборд теряет демо-секции e-commerce (best sellers, low stock, recent orders, campaigns, brands) и собирается из реальных данных платформы имеющимися компонентами (KPI, график выручки, топ-страницы, свежие посты); KPI-карточки blogs/customers теряют захардкоженные дельты/спарклайны и долларовые/tier-метрики, которых у платформы нет.
- Эталон `frontends/source-admin` не меняется (никакого зеркалирования); правки выполняются только в `frontends/admin`.

## Capabilities

### New Capabilities

- `console-service-management`: экран управления активными сервисами проекта в консоли — галочки переключаемых сервисов с отражением в навигации.

### Modified Capabilities

- `admin-console`: требование «вёрстка переносится без изменений (тексты MUST NOT изменяться)» ослабляется — тексты локализуются через реестр `console.*` со словарём переводов; нерелевантные платформе фрагменты шаблона (долларовые метрики, демо-секции) в живых разделах убираются; структура/компоненты остаются шаблонными.
- `console-navigation`: состав сайдбара отражает переключение сервисов без повторного входа (обновление снапшота после toggle).
- `console-localization-ui`: словарь переводов дополнительно служит источником текстов самой консоли (ключи `console.*`, локаль оператора, кэш по версии словаря).

## Impact

- Код: только `frontends/admin/src` (реестр текстов + `t()`, тип `PlatformBootstrap` += `translations_version`/`user.locale`, вкладка Services, чистка categories/dashboard/KPI, замена строк на ключи). Бэкенд не меняется (эндпоинты словаря и сервисов готовы).
- Тесты: `frontends/admin` node-тесты (section-access — расширение на обновление снапшота; новый тест реестра текстов), e2e `console-navigation.spec.ts` (переключение сервисов из UI), `localization.spec.ts` (русские тексты).
- Предположение (зафиксировано): скрытые демо-разделы шаблона (products, orders, inventory, promotions, campaigns, support, notifications, brands, collections, variants) не русифицируются и не чистятся — они не видны оператору (`isDemoSection`), их перевод выполняется при будущем подключении к платформе.
- Предположение: русский — язык консоли по умолчанию (`user.locale`, дефолт `ru`); другие языки оператор получает переопределением ключей `console.*` в словаре своего проекта.
