# Proposal: cms-ai-package

## Why

Платформе предстоит несколько AI-возможностей: редактирование и нормализация текста, генерация категорий и постов, автоперевод локализаций (следующее изменение `cms-localization-package` прямо на это опирается). Сегодня для этого нет ничего: ни клиента, ни контракта, и каждый сервис, которому понадобится AI, начал бы городить своё. Контракт важно заложить правильно один раз — потребителей будет много, а менять интерфейс после того, как на него сядут content, localization и панель, дорого.

Провайдер по умолчанию — Polza (OpenAI-совместимый API, `https://polza.ai/api/v1`), но привязываться к нему нельзя: провайдер и ключ должны переопределяться из окружения (`OPENAI_*`), чтобы деплой мог перейти на другой совместимый сервис без правки кода.

## What Changes

- **Новый пакет `packages/cms/ai`** по канону DDD/CQRS платформы: доменный контракт (порт) + инфраструктурный адаптер на официальном SDK `laravel/ai`.
- **Контракт из пяти операций**, закрывающий заявленных потребителей:
  - `rewrite` — редактирование текста по инструкции (тон, стиль, сокращение);
  - `normalize` — нормализация текста (очистка, пунктуация, единый регистр/формат);
  - `translate` — перевод набора строк на целевые локали (основа AI-переводов локализации);
  - `suggestCategories` — предложение дерева категорий для проекта по его описанию;
  - `generatePost` — черновик поста (заголовок, slug, тело) по теме и указаниям.
- **Структурные ответы, а не сырой текст**: каждая операция возвращает типизированный DTO; ответы модели валидируются схемой (structured output `laravel/ai`), невалидный ответ — это ошибка операции, а не мусор дальше по конвейеру.
- **Конфигурация только из ENV**: провайдер, ключ, базовый URL, модель, таймаут — `config/cms-ai.php`, читающий `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `CMS_AI_MODEL` и т.п. Polza — значение по умолчанию для base URL; секретов в коде и конфиге нет.
- **Устойчивость**: ошибки провайдера оборачиваются в доменное исключение пакета; вызовы ограничены таймаутом; операции пригодны для вызова из Jobs (тяжёлые генерации — только через очередь, по канону платформы).
- **Не входит**: HTTP-эндпоинты и UI (потребители подключают пакет сами в своих изменениях); embeddings и транскрипция (отдельные возможности Polza — добавятся, когда появится потребитель); стриминг ответов; учёт токенов/биллинг.

## Capabilities

### New Capabilities

- `ai-operations`: единый контракт AI-операций платформы (редактирование, нормализация, перевод, генерация категорий и постов) со структурными ответами, провайдером из окружения и предсказуемым поведением при отказе.

### Modified Capabilities

нет.

## Impact

- Новый пакет `packages/cms/ai` (Domain/Contracts — порт, Application/DTOs — запросы и ответы операций, Infrastructure — адаптер `laravel/ai` + конфиг). Подключается в сервисы через composer path-репозиторий, как остальные `cms/*`.
- `composer require laravel/ai` в сервисах-потребителях (сначала content-service — он первый потребитель через localization).
- `.env.example` сервисов — блок `OPENAI_API_KEY`, `OPENAI_BASE_URL` (default `https://polza.ai/api/v1`), `CMS_AI_MODEL`, `CMS_AI_TIMEOUT`.
- Тесты — Pest на уровне контракта с фейковым провайдером (`laravel/ai` поддерживает фейки); сетевых вызовов в тестах нет.
- Зависимых изменений нет; `cms-localization-package` планируется поверх этого контракта.
