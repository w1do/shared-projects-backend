# content-posts

## ADDED Requirements

### Requirement: Изображения поста

Пост SHALL иметь обложку и баннер — по одному изображению из медиатеки проекта на каждое. Блок изображений SHALL показываться в форме поста по умолчанию, без включения дополнительных настроек. Оба изображения MAY быть пустыми: пост без изображений остаётся допустимым. Выбранные изображения MUST сохраняться вместе с постом и быть видны после повторного открытия поста. Список постов SHALL показывать обложку поста, а при её отсутствии — единообразную заглушку.

#### Scenario: Блок изображений виден сразу

- **WHEN** оператор открывает создание поста
- **THEN** блок изображений с обложкой и баннером показан в форме без дополнительных действий

#### Scenario: Изображение переживает перезагрузку

- **WHEN** оператор задал обложку поста и заново открыл пост
- **THEN** обложка отображается прежней

#### Scenario: Пост без изображений

- **WHEN** оператор сохраняет пост, не задав ни обложку, ни баннер
- **THEN** пост сохраняется, в списке у него показана заглушка вместо обложки

### Requirement: Изображение поста хранится в медиатеке проекта

Изображение, выбранное для поста, MUST храниться в медиатеке текущего проекта и отдаваться по ссылке платформы. Загруженный оператором файл MUST попадать в хранилище проекта до сохранения поста; пост MUST NOT хранить изображение содержимым формы. Оператор SHALL видеть ход загрузки и понятное сообщение при отказе; при отказе загрузки прежнее изображение поста MUST оставаться прежним.

#### Scenario: Загрузка файла оператором

- **WHEN** оператор выбирает файл изображения в форме поста
- **THEN** файл попадает в медиатеку проекта, а в форме показывается изображение по ссылке платформы

#### Scenario: Отказ загрузки

- **WHEN** платформа отклоняет загрузку файла
- **THEN** оператор видит понятное сообщение, изображение поста не меняется

#### Scenario: Снятие изображения

- **WHEN** оператор убирает обложку у поста и сохраняет его
- **THEN** пост остаётся без обложки, файл в медиатеке проекта сохраняется

### Requirement: Подбор изображения поста поиском

Блок изображений поста SHALL содержать действие подбора изображения. По текстовому запросу оператора консоль SHALL показывать сетку найденных изображений с превью и источником, позволять выбрать одно и подставить его в обложку или баннер после переноса в медиатеку проекта. Действие MUST быть доступно только оператору с правом управления медиа. Запрос по умолчанию SHALL предзаполняться заголовком поста, оставаясь правимым. До выбора оператором пост MUST NOT изменяться.

#### Scenario: Подбор и выбор изображения

- **WHEN** оператор вызывает подбор изображения, вводит запрос и выбирает результат
- **THEN** изображение переносится в медиатеку проекта и подставляется в поле, из которого вызван подбор

#### Scenario: Запрос предзаполнен

- **WHEN** оператор вызывает подбор у поста с заголовком
- **THEN** поле запроса предзаполнено заголовком и доступно для правки

#### Scenario: Отказ от выбора

- **WHEN** оператор закрывает подбор, ничего не выбрав
- **THEN** изображения поста не меняются, в медиатеку ничего не добавляется

#### Scenario: Нет права на медиа

- **WHEN** пост открывает оператор без права управления медиа
- **THEN** действие подбора изображения не показывается
