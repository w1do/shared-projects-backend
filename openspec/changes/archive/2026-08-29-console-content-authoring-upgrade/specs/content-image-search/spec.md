# content-image-search

## Purpose
Определяет подбор изображения для материалов проекта: оператор ищет картинку по текстовому запросу во внешней поисковой службе, выбирает подходящую из выдачи, и платформа переносит её в медиатеку проекта, чтобы дальнейшая работа шла только с собственным хранилищем.

## ADDED Requirements

### Requirement: Поиск изображений по запросу

Платформа SHALL предоставлять поиск изображений по текстовому запросу через ту же внешнюю поисковую службу, что используется для ресёрча. Ответ SHALL содержать для каждого результата ссылку на изображение, ссылку на превью, размеры и источник страницы. Число результатов SHALL быть ограничено и настраиваться окружением. Поиск MUST NOT сохранять найденные изображения сам по себе.

#### Scenario: Выдача по запросу

- **WHEN** оператор запрашивает изображения по текстовому запросу
- **THEN** возвращается ограниченный список результатов, у каждого — превью, ссылка на изображение и источник

#### Scenario: Ничего не найдено

- **WHEN** внешняя служба не вернула ни одного изображения
- **THEN** платформа отвечает пустым списком, а не ошибкой

#### Scenario: Служба недоступна

- **WHEN** внешняя поисковая служба недоступна или отклонила запрос
- **THEN** оператор видит понятное сообщение, ничего в медиатеку не попадает

#### Scenario: Ключ поиска не настроен

- **WHEN** ключ доступа к поисковой службе не задан в окружении
- **THEN** запрос отклоняется с понятным сообщением о ненастроенной интеграции

### Requirement: Импорт выбранного изображения в медиатеку проекта

Платформа SHALL импортировать выбранное оператором изображение по его ссылке в медиатеку текущего проекта. Импортированный файл MUST принадлежать проекту и храниться в том же хранилище, что и загруженные вручную медиа, и MUST быть доступен по собственной ссылке платформы. Внешняя ссылка MUST NOT сохраняться как адрес изображения материала. Импорт SHALL проверять, что по ссылке действительно изображение допустимого типа и размера; недопустимый файл MUST отклоняться без создания записи медиа.

#### Scenario: Выбранное изображение попадает в медиатеку

- **WHEN** оператор выбирает изображение из выдачи поиска
- **THEN** платформа скачивает его, создаёт медиа-файл проекта и возвращает ссылку платформы на него

#### Scenario: По ссылке не изображение

- **WHEN** ссылка ведёт на файл недопустимого типа или превышающий предел размера
- **THEN** импорт отклоняется с понятным сообщением, запись медиа не создаётся

#### Scenario: Ссылка недоступна

- **WHEN** изображение по ссылке не скачивается
- **THEN** оператор видит понятное сообщение и может выбрать другой результат

#### Scenario: Импортированное изображение доступно как своё

- **WHEN** оператор открывает материал с импортированным изображением
- **THEN** изображение отдаётся по ссылке платформы и не зависит от доступности внешнего источника

### Requirement: Подбор изображения доступен по праву на медиа

Поиск изображений и импорт SHALL быть доступны только оператору с правом управления медиа текущего проекта. Оператор без этого права MUST NOT видеть действие подбора и MUST получать отказ при прямом обращении.

#### Scenario: Нет права на медиа

- **WHEN** оператор без права управления медиа запрашивает поиск изображений
- **THEN** запрос отклоняется отказом по правам, поиск не выполняется
