## Why

Переключатели сервисов в настройках включают сервис, но не открывают его разделы: включённая «Оплата» не даёт в сайдбаре ни транзакций, ни подписок, ни тарифных планов — платёжный API есть, экранов нет. Лицензирование живёт отдельным тумблером и отдельной группой «Продажи», хотя это часть оплаты. Разделы контента разбросаны по трём группам, а SEO — полноценная сущность платформы (`seo_meta` с десятком полей) — вообще не имеет экрана: поля правятся только по одной записи в карточке поста. И «Собрать проект по AI» заперт на дашборде: выключена аналитика — оператор теряет доступ к сборке проекта, хотя сборка к аналитике отношения не имеет.

## What Changes

**Сайдбар — группы по сервисам**

- Группа **«Оплата»** (тумблер `pay`): Транзакции оплат, Подписки, Тарифные планы, Тарифные планы лицензий, Лицензии, Организации, Релизы. Каждый пункт — свой маршрут.
- Группа **«Контент»** (тумблер `content`): Блог, Категории, Ресёрч, Инструкции, SEO.
- Группы «Каталог», «Продажи», «Рабочее пространство» перестраиваются: остаются «Обзор» (Дашборд) и «Рабочее пространство» (Клиенты, Команда, Настройки).

**Лицензирование уходит под тумблер оплаты**

- **BREAKING**: сервис `licensing` перестаёт быть переключаемым — тумблер убирается из настроек, admin-маршруты лицензирования гейтятся сервисом `pay`.
- Страница `/admin/licensing` с четырьмя вкладками разбирается на четыре отдельных экрана в группе «Оплата». Права `pay.licensing.view|manage` не переименовываются.
- Миграция: проектам с включённым `licensing` включается `pay`, чтобы лицензирование не пропало из консоли.

**Новые экраны оплаты**

- Транзакции оплат — список платежей проекта с подтверждением и возвратом (`pay/payments`).
- Подписки — список подписок с фильтром по предмету, включая подписки на планы лицензий, и действиями оператора (`pay/subscriptions`).
- Тарифные планы — планы подписок pay (`pay/plans`), отдельно от планов лицензий (`pay/licensing/plans`).

**Раздел SEO**

- Единая таблица SEO по постам, категориям и страницам: все поля `seo_meta` (title, description, keywords, canonical, robots, og:title, og:description, og:image, twitter card, JSON-LD), фильтр по типу сущности и сортировка.
- Правка записи прямо из раздела.
- Пересбор полей по AI: для выбранных строк и для всех — фоновой задачей с видимым прогрессом и причиной отказа.

**Сборка проекта по AI переезжает в настройки**

- Карточка проекта (идентификатор, название, описание, запуск сборки по AI) уходит с дашборда в Настройки → Основные; идентификатор проекта выводится сверху раздела.
- На дашборде карточки проекта больше нет.

## Capabilities

### New Capabilities

- `console-pay-ui`: разделы оплаты в консоли — транзакции оплат, подписки, тарифные планы подписок: состав, действия оператора, режим только чтения без права manage.
- `console-seo-ui`: раздел SEO в консоли — таблица всех SEO-полей по сущностям контента, фильтр и сортировка, правка записи, запуск AI-пересбора для выбранных и для всех.
- `content-seo-catalog`: API каталога SEO проекта (список записей по типам сущностей с сортировкой и пагинацией) и фоновый AI-пересбор SEO-полей.

### Modified Capabilities

- `console-navigation`: состав и группировка меню — группы «Оплата» и «Контент» собираются по тумблерам сервисов; новые ключи разделов и их требования (сервис + право).
- `console-service-management`: список переключаемых сервисов сокращается до трёх — контент, аналитика, оплата.
- `console-licensing-ui`: единый раздел с вкладками заменяется четырьмя разделами группы «Оплата»; видимость — по сервису `pay`.
- `console-project-overview`: карточка проекта и запуск сборки по AI переносятся с дашборда в Настройки → Основные.
- `licensing/service-registration`: **BREAKING** — `licensing` больше не переключаемый сервис; гейт admin-маршрутов — по `pay`; публичная валидация ключей по-прежнему вне переключателя.

## Impact

**Бэкенд**

- `packages/cms/auth`: `ServiceName::toggleable()` без `licensing`, `cms-auth.php` (`default_enabled_services`), enum сервиса в `ServiceController`, миграция включения `pay` проектам с `licensing`.
- `packages/cms/licensing`: `routes/admin.php` — `EnsureServiceEnabled:pay`; `LicensingManifest` — навигация четырьмя пунктами.
- `packages/cms/pay`: `PayManifest` — навигация пунктами транзакций, подписок и планов.
- `packages/cms/content`: новые query/handler/controller каталога SEO, Job AI-пересбора, `BackgroundTaskKind::SeoRebuild`, маршруты `content/seo`.
- `packages/cms/shared`: новый вид фоновой задачи.

**Консоль**

- `frontends/admin/src/lib/admin/sidebar-config.ts`, `lib/admin/data-source/section-access.ts` (ключи разделов и их требования), `proxy.ts` (гейт маршрутов).
- Новые маршруты `app/admin/{payments,subscriptions,plans,license-plans,licenses,organizations,releases,seo}` и их страницы; `components/pages/licensing/*` разбирается на разделы.
- `components/pages/dashboard/sections/ProjectCard/*` → `components/pages/settings/sections/`.
- Вёрстка новых экранов берётся из склада `frontends/source-admin` (`components/pages/orders/*` — таблица транзакций).

**Совместимость**

- Права не меняются: `pay.licensing.*`, `pay.payments.*`, `pay.plans.*`, `pay.subscriptions.*`, `content.seo.manage`.
- Адрес `/admin/licensing` исчезает; закладки операторов на него перестают работать.
