# analytics-service — delta

## MODIFIED Requirements

### Requirement: Экспорт отчётов

Экспорт SHALL выполняться асинхронно фоновой задачей с последующей выдачей файла. Период отчётов и экспорта SHALL приниматься только из query-string (`from`, `to`); тело запроса SHALL игнорироваться целиком — и при чтении, и при валидации. Невалидные значения в query SHALL давать 422; при отсутствии параметров действует окно последних 30 дней.

#### Scenario: Экспорт большого отчёта

- WHEN оператор запускает экспорт
- THEN запрос завершается сразу, файл доступен позже

#### Scenario: Даты в теле запроса экспорта

- WHEN POST /export получает from/to только в JSON-теле
- THEN тело игнорируется, экспорт ставится с дефолтным окном, ответ 202

#### Scenario: Невалидная дата в query

- WHEN GET /overview вызван с ?from=not-a-date
- THEN возвращается 422 с ключом from в error.details
