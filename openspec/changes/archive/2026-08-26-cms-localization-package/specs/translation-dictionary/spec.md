# translation-dictionary

## Purpose

Хранит переводы интерфейсных строк проекта в виде «ключ → значения по локалям», позволяет управлять ими из API и отдаёт панели словарь нужной локали с версией для кэширования.

## ADDED Requirements

### Requirement: Ключ хранит значения по локалям проекта

Словарь SHALL хранить записи вида «ключ → набор значений по локалям» в пределах проекта. Ключ MUST быть уникален в проекте. Значения SHALL допускаться только для локалей, объявленных у проекта; попытка записать значение неизвестной локали MUST отклоняться.

#### Scenario: Запись с несколькими локалями

- **WHEN** оператор сохраняет ключ `nav.categories` со значениями `en: Categories` и `ru: Категории`
- **THEN** обе локали читаются обратно по этому ключу

#### Scenario: Неизвестная локаль

- **WHEN** значение записывается для локали, не объявленной у проекта
- **THEN** запись отклоняется с понятной ошибкой

### Requirement: Управление словарём через API с правами

Платформа SHALL предоставлять API создания, изменения, удаления и чтения записей словаря, закрытое правами контента. Оператор без права управления переводами MUST NOT изменять словарь.

#### Scenario: Изменение значения

- **WHEN** оператор с правом управления меняет значение локали у ключа
- **THEN** новое значение сохраняется, прочие локали ключа не затронуты

#### Scenario: Нет права

- **WHEN** запись изменяет оператор без соответствующего права
- **THEN** запрос отклоняется, словарь не меняется

### Requirement: Словарь отдаётся панели по локали с версией

Платформа SHALL отдавать словарь проекта для запрошенной локали одним запросом (ключ → значение). Версия переводов SHALL расти при любом изменении словаря и MUST отдаваться в `bootstrap`, чтобы панель могла кэшировать словарь и обнаруживать устаревание. Для ключа без значения запрошенной локали SHALL возвращаться значение локали проекта по умолчанию.

#### Scenario: Загрузка словаря локали

- **WHEN** панель запрашивает словарь локали `ru`
- **THEN** она получает пары «ключ → русское значение», с подстановкой значения локали по умолчанию там, где русского нет

#### Scenario: Версия растёт при изменении

- **WHEN** запись словаря изменена
- **THEN** `translations_version` в `bootstrap` становится больше прежнего
