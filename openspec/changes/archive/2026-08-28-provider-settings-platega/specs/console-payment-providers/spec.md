# console-payment-providers — Delta

## Purpose

Консольный UI управления настройками платёжного провайдера: шестерёнка на карточке провайдера в «Настройки → Платежи», модальное окно с удобной формой JSON-полей и копированием настроек с другого проекта.

## ADDED Requirements

### Requirement: Открытие настроек провайдера
На карточке платёжного провайдера (Platega) в разделе «Настройки → Платежи» SHALL отображаться кнопка-шестерёнка; нажатие SHALL открывать модальное окно с формой настроек провайдера текущего проекта (существующие значения предзаполнены).

#### Scenario: Шестерёнка открывает модальное окно
- **WHEN** оператор нажимает шестерёнку на карточке Platega
- **THEN** открывается модальное окно с текущими настройками провайдера этого проекта

### Requirement: Форма настроек провайдера
Форма SHALL содержать: редакторы JSON-полей `credentials` и `properties`, поля `return_url` и `fail_url`, переключатель статуса `active`/`archive`. JSON-поля SHALL заполняться двумя способами на выбор: как набор строк «ключ → значение» (добавление/удаление строк) или вставкой сырого JSON с переключением режима; режимы SHALL быть согласованы (введённое в одном режиме видно в другом). Невалидный JSON SHALL блокировать сохранение с понятной ошибкой.

#### Scenario: Заполнение key → value
- **WHEN** оператор добавляет в credentials строки «ключ → значение» и сохраняет форму
- **THEN** настройки сохраняются, повторное открытие окна показывает те же пары

#### Scenario: Вставка сырого JSON
- **WHEN** оператор переключает редактор в режим JSON, вставляет валидный JSON-объект и сохраняет
- **THEN** настройки сохраняются, в режиме «ключ → значение» отображаются пары из вставленного JSON

#### Scenario: Невалидный JSON не сохраняется
- **WHEN** оператор вставляет некорректный JSON и пытается сохранить
- **THEN** форма показывает ошибку, запрос на сохранение не отправляется

### Requirement: Копирование настроек с другого проекта
В модальном окне SHALL быть действие «Скопировать с проекта»: оператор выбирает один из доступных ему проектов, и все настройки этого провайдера из выбранного проекта (credentials, properties, URL-ы, статус) SHALL подставляться в форму. Применение скопированных значений SHALL происходить только после явного сохранения формы оператором.

#### Scenario: Копирование заполняет форму
- **WHEN** оператор выбирает проект-источник и нажимает «Скопировать с проекта»
- **THEN** форма заполняется настройками Platega из выбранного проекта без немедленного сохранения

#### Scenario: Сохранение скопированных настроек
- **WHEN** после копирования оператор нажимает «Сохранить»
- **THEN** настройки текущего проекта обновляются скопированными значениями

### Requirement: Локализация текстов
Все тексты модального окна и кнопок SHALL выводиться через словарь консоли (никаких строковых литералов в компонентах).

#### Scenario: Тексты берутся из словаря
- **WHEN** консоль отображает модальное окно настроек провайдера
- **THEN** все подписи, плейсхолдеры и сообщения об ошибках берутся из ключей словаря консоли
