# Tasks — refactor-ddd-cqrs-packages

Охват: шесть модуль-пакетов (`analytics`, `localization`, `ai`, `content`, `auth`, `pay`) + три библиотеки (`shared`, `contracts`, `generators`).

Гейт каждого этапа: `composer lint && composer stan && composer test` соответствующего сервиса зелёные; публичные HTTP-контракты не изменились.

Конвейер каждого контроллера после рефакторинга: FormRequest (`Presentation/Http/Api/V1/Requests/<Сущность>/`) → DTO (без `rules()`, без импортов `Illuminate\Http\*`) → Handler → JsonResource (`Presentation/Http/Api/V1/Resources/<Сущность>/`). Порядок этапов — Decision 13: сначала shared-фундамент, затем пакеты по возрастанию риска.
