# settings/site-preferences Specification

## Purpose
Централизованные настройки проекта через spatie/laravel-settings: текущий язык, валюты и связанные параметры.

## Requirements

### Requirement: Управление языком проекта
Система SHALL позволять устанавливать и получать текущий язык проекта из настроек. Язык по умолчанию MUST быть одним из языков, привязанных к проекту; попытка задать язык вне этого набора SHALL отклоняться. Набор языков проекта SHALL быть доступен вместе с настройками, чтобы выбор языка по умолчанию делался из него.

#### Scenario: Смена языка
- **WHEN** администратор меняет язык в настройках
- **THEN** новый язык становится активным для локализаций и интерфейса

#### Scenario: Язык вне набора проекта
- **WHEN** администратор задаёт языком по умолчанию локаль, не привязанную к проекту
- **THEN** запрос отклоняется с понятным сообщением, прежний язык сохраняется

### Requirement: Управление валютами (RUB/USD)
Система SHALL хранить список поддерживаемых валют и текущую валюту по умолчанию. Допустимые валюты — рубль (RUB) и доллар США (USD); значение вне этого набора SHALL отклоняться. Валюта по умолчанию MUST входить в список поддерживаемых валют проекта.

#### Scenario: Выбор валюты по умолчанию
- **WHEN** администратор выбирает валюту по умолчанию
- **THEN** цены и денежные значения отображаются в выбранной валюте согласно бизнес‑логике

#### Scenario: Валюта вне набора
- **WHEN** администратор задаёт валюту, не входящую в поддерживаемые
- **THEN** запрос отклоняется, настройки не меняются

### Requirement: Тип проекта и часовой пояс

Настройки проекта SHALL хранить тип проекта и часовой пояс. Тип проекта MUST быть одним из: блог, интернет-магазин, корпоративный сайт, лендинг. Часовой пояс MUST выбираться из часовых поясов России. Значения MUST храниться в настройках проекта платформы, быть tenant-scoped и переживать перезагрузку консоли; хранение на стороне браузера MUST NOT использоваться. Новый проект SHALL получать значения по умолчанию: тип «блог» и часовой пояс `Europe/Moscow`. Название и описание сайта MUST NOT дублироваться в настройках: они остаются полями проекта.

#### Scenario: Сохранение типа и часового пояса

- **WHEN** администратор меняет тип проекта и часовой пояс и сохраняет
- **THEN** значения сохраняются в платформе и после перезагрузки консоли показываются прежними

#### Scenario: Настройки принадлежат проекту

- **WHEN** администратор переключается на другой проект
- **THEN** показываются настройки этого проекта, а не прежнего

#### Scenario: Недопустимый тип проекта

- **WHEN** задаётся тип проекта вне допустимого набора
- **THEN** запрос отклоняется с понятным сообщением, настройки не меняются

#### Scenario: Значения нового проекта

- **WHEN** создан новый проект
- **THEN** его тип и часовой пояс заполнены значениями по умолчанию и доступны на чтение
