# ai-project-buildout Specification

## Purpose
Определяет сборку проекта по AI: оператор одним действием получает заполненное описание проекта и дерево категорий, построенные моделью по инструкции проекта, вместо того чтобы заводить всё вручную.

## Requirements

### Requirement: Запуск сборки проекта

Оператор с правом управления проектом SHALL иметь возможность запустить сборку проекта по AI, указав тематику проекта. Сборка SHALL выполняться в фоне; ответ на запуск SHALL возвращаться сразу с состоянием «выполняется». Оператор SHALL видеть, чем закончилась сборка.

#### Scenario: Оператор запускает сборку

- **WHEN** оператор запускает сборку проекта с тематикой «автомобили»
- **THEN** ответ возвращается сразу, сборка отмечена как выполняющаяся

#### Scenario: Нет права

- **WHEN** сборку запускает оператор без права управления проектом
- **THEN** запуск отклоняется, проект не изменяется

#### Scenario: Повторный запуск во время работы

- **WHEN** оператор запускает сборку, пока предыдущая ещё выполняется
- **THEN** новая сборка не создаётся, оператор получает понятное сообщение о текущей

### Requirement: Состав ответа задаётся инструкцией

Что именно возвращает модель при сборке, SHALL определяться инструкцией проекта: её правило задаёт задачу, её схема — форму ответа. Схема SHALL описывать поля проекта и список категорий одним ответом. Изменение состава собираемых данных MUST достигаться правкой инструкции, а не изменением кода.

#### Scenario: Состав меняется правкой инструкции

- **WHEN** оператор добавляет поле в схему инструкции сборки и запускает сборку
- **THEN** модель возвращает это поле, и платформа применяет его без изменений кода

#### Scenario: Ответ не соответствует схеме

- **WHEN** ответ модели не соответствует схеме инструкции сборки
- **THEN** сборка завершается неуспешно, проект и категории не изменяются

### Requirement: Применение результата сборки

Результат сборки SHALL заполнять описание и тематику проекта и создавать категории проекта по возвращённому дереву. Категории MUST создаваться с сохранением вложенности. Существующая категория с тем же адресом MUST NOT дублироваться: она SHALL сохраняться как есть. Уже заполненные поля проекта MUST NOT затираться без явного согласия оператора.

#### Scenario: Проект заполнен и категории созданы

- **WHEN** сборка завершилась успешно для пустого проекта
- **THEN** у проекта заполнены описание и тематика, а категории созданы с сохранением вложенности

#### Scenario: Категория уже существует

- **WHEN** возвращённая категория совпадает по адресу с существующей
- **THEN** существующая категория остаётся без изменений, дубликат не создаётся

#### Scenario: Описание уже заполнено

- **WHEN** сборка запущена для проекта с заполненным описанием, и оператор не подтвердил перезапись
- **THEN** прежнее описание сохраняется, а категории всё равно создаются

### Requirement: Применение результата не оставляет полурезультата

Создание категорий SHALL применяться целиком или не применяться вовсе: ошибка на середине списка MUST NOT оставлять часть дерева созданной. Заполнение полей проекта SHALL применяться одним изменением. Незавершённое применение SHALL повторяться, и повтор MUST быть идемпотентным: он MUST NOT дублировать уже созданные категории и MUST NOT перезаписывать поля, заполненные предыдущей попыткой.

#### Scenario: Ошибка при создании категорий

- **WHEN** создание категорий прервалось ошибкой на середине списка
- **THEN** дерево категорий остаётся в состоянии, бывшем до запуска сборки

#### Scenario: Повтор после частичного применения

- **WHEN** категории созданы, а заполнение полей проекта не удалось и применение повторяется
- **THEN** категории не дублируются, поля проекта заполняются, сборка завершается успешно

### Requirement: Сборка ограничена своим проектом

Сборка SHALL изменять только тот проект, из которого запущена. Ни одно поле и ни одна категория другого проекта MUST NOT изменяться.

#### Scenario: Сборка не затрагивает соседний проект

- **WHEN** сборка выполнена в одном проекте
- **THEN** описание и категории других проектов остаются прежними
