# console-project-overview Specification

## Purpose
Определяет, что оператор видит и может сделать с текущим проектом на главной странице консоли: карточку с идентификатором, названием и описанием проекта и запуск сборки проекта по AI.

## Requirements

### Requirement: Карточка проекта на дашборде

Главная страница консоли SHALL показывать карточку текущего проекта: идентификатор, название и описание. Данные MUST приходить из платформы, а не быть зашитыми в вёрстку. Идентификатор SHALL быть доступен для копирования одним действием.

#### Scenario: Оператор видит проект

- **WHEN** оператор открывает главную страницу консоли
- **THEN** он видит идентификатор, название и описание текущего проекта

#### Scenario: Описание не заполнено

- **WHEN** у проекта нет описания
- **THEN** карточка показывает подсказку о незаполненном описании и предлагает собрать проект по AI

#### Scenario: Смена проекта

- **WHEN** оператор переключается на другой проект
- **THEN** карточка показывает данные выбранного проекта

### Requirement: Правка названия и описания проекта

Оператор с правом управления проектом SHALL иметь возможность изменить название и описание проекта из карточки. Сохранённые изменения MUST быть видны после перезагрузки страницы. Оператору без права правки элементы изменения MUST NOT показываться.

#### Scenario: Правка описания

- **WHEN** оператор изменяет описание проекта и сохраняет
- **THEN** новое описание отображается и сохраняется после перезагрузки

#### Scenario: Нет права управления

- **WHEN** карточку открывает оператор без права управления проектом
- **THEN** он видит данные проекта, но не видит элементов правки

### Requirement: Запуск сборки проекта по AI с дашборда

Карточка проекта SHALL содержать действие «Собрать проект по AI». Действие SHALL запрашивать тематику проекта и запускать сборку. Пока сборка идёт, консоль SHALL показывать её ход и MUST NOT позволять запустить вторую сборку. По завершении консоль SHALL показать результат и обновить карточку проекта.

#### Scenario: Запуск сборки

- **WHEN** оператор нажимает «Собрать проект по AI» и указывает тематику
- **THEN** консоль показывает, что сборка идёт, и кнопка повторного запуска недоступна

#### Scenario: Сборка завершилась

- **WHEN** сборка завершилась успешно
- **THEN** карточка проекта показывает заполненное описание, а оператору сообщается, сколько категорий создано

#### Scenario: Сборка не удалась

- **WHEN** сборка завершилась ошибкой
- **THEN** оператор видит сообщение об ошибке и может запустить сборку повторно

#### Scenario: Действие скрыто без права

- **WHEN** дашборд открывает оператор без права управления проектом
- **THEN** действие «Собрать проект по AI» не показывается
