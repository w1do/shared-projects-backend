# console-project-overview Specification

## Purpose
Определяет, что оператор видит и может сделать с текущим проектом на главной странице консоли: карточку с идентификатором, названием и описанием проекта и запуск сборки проекта по AI.

## Requirements

### Requirement: Карточка проекта на дашборде

Карточка текущего проекта SHALL отображаться в разделе «Основные» настроек консоли: идентификатор, название и описание. Идентификатор проекта SHALL выводиться в начале раздела, над полями настроек, и быть доступен для копирования одним действием. Данные MUST приходить из платформы, а не быть зашитыми в вёрстку. Главная страница консоли MUST NOT показывать карточку проекта.

#### Scenario: Оператор видит проект

- **WHEN** оператор открывает раздел «Основные» настроек
- **THEN** он видит идентификатор проекта сверху раздела, а также его название и описание

#### Scenario: Описание не заполнено

- **WHEN** у проекта нет описания
- **THEN** раздел показывает подсказку о незаполненном описании и предлагает собрать проект по AI

#### Scenario: Смена проекта

- **WHEN** оператор переключается на другой проект
- **THEN** раздел показывает данные выбранного проекта

#### Scenario: Дашборд без карточки

- **WHEN** оператор открывает главную страницу консоли
- **THEN** карточка проекта на ней отсутствует

### Requirement: Правка названия и описания проекта

Оператор с правом управления проектом SHALL иметь возможность изменить название и описание проекта из раздела «Основные» настроек. Сохранённые изменения MUST быть видны после перезагрузки страницы. Оператору без права правки элементы изменения MUST NOT показываться.

#### Scenario: Правка описания

- **WHEN** оператор изменяет описание проекта и сохраняет
- **THEN** новое описание отображается и сохраняется после перезагрузки

#### Scenario: Нет права управления

- **WHEN** раздел открывает оператор без права управления проектом
- **THEN** он видит данные проекта, но не видит элементов правки

### Requirement: Запуск сборки проекта по AI с дашборда

Раздел «Основные» настроек SHALL содержать действие «Собрать проект по AI». Действие SHALL запрашивать тематику проекта и запускать сборку. Доступность действия MUST NOT зависеть от включённости сервиса аналитики. Пока сборка идёт, консоль SHALL показывать её ход и MUST NOT позволять запустить вторую сборку. По завершении консоль SHALL показать результат и обновить данные проекта в разделе.

#### Scenario: Запуск сборки

- **WHEN** оператор нажимает «Собрать проект по AI» и указывает тематику
- **THEN** консоль показывает, что сборка идёт, и кнопка повторного запуска недоступна

#### Scenario: Сборка завершилась

- **WHEN** сборка завершилась успешно
- **THEN** раздел показывает заполненное описание проекта, а оператору сообщается, сколько категорий создано

#### Scenario: Сборка не удалась

- **WHEN** сборка завершилась ошибкой
- **THEN** оператор видит сообщение об ошибке и может запустить сборку повторно

#### Scenario: Аналитика выключена

- **WHEN** сервис аналитики выключен для проекта
- **THEN** действие «Собрать проект по AI» остаётся доступным в разделе «Основные»

#### Scenario: Действие скрыто без права

- **WHEN** раздел открывает оператор без права управления проектом
- **THEN** действие «Собрать проект по AI» не показывается
