# analytics/providers-config Specification

## Purpose
Конфигурация провайдеров аналитики (Yandex/Google): хранение ID счётчиков и использование их в админке и фронтенде.

## Requirements

### Requirement: Хранение идентификаторов провайдеров
Система SHALL хранить идентификаторы счётчиков для Yandex и Google в настройках.

#### Scenario: Сохранение ID
- **WHEN** администратор вводит и сохраняет ID провайдера
- **THEN** значение доступно для чтения сервисами рендеринга/инъекции скриптов

### Requirement: Включение/отключение провайдера
Система SHALL позволять включать или отключать каждого провайдера независимо.

#### Scenario: Отключение провайдера
- **WHEN** администратор отключает провайдера
- **THEN** скрипты и события этого провайдера не инициализируются
