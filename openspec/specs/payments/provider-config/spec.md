# payments/provider-config Specification

## Purpose
Единая конфигурация платёжного провайдера: выбор Platega и упразднение параметров доставки/налогов в этом разделе.

## Requirements

### Requirement: Выбор платёжного провайдера
Система SHALL позволять выбирать активного платёжного провайдера из списка, минимум Platega. Список допустимых значений SHALL формироваться из реестра реально зарегистрированных шлюзов (без жёстко зашитых значений вне реестра). Инициализация платежа без явно указанного провайдера SHALL использовать провайдера, выбранного в настройках платежей проекта.

#### Scenario: Активация Platega
- **WHEN** администратор выбирает Platega в настройках платежей
- **THEN** система использует Platega для инициации и обработки платежей

#### Scenario: Инициализация платежа уважает настройки
- **WHEN** в настройках платежей проекта выбран провайдер `platega` и платёж инициируется без явного указания провайдера
- **THEN** платёж проводится через шлюз Platega по настройкам провайдера этого проекта

#### Scenario: Неизвестный провайдер отклоняется
- **WHEN** администратор пытается сохранить провайдера, отсутствующего в реестре шлюзов
- **THEN** система возвращает ошибку валидации

### Requirement: Сокращение настроек раздела
Система SHALL скрыть/удалить из настроек платежей параметры, не относящиеся к провайдеру (доставка, налоги).

#### Scenario: Параметры доставки и налогов не отображаются
- **WHEN** администратор открывает раздел «Платежи»
- **THEN** параметры доставки и налогов отсутствуют в UI и конфигурации раздела
