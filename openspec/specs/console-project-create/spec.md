# console-project-create Specification

## Purpose
Определяет создание нового проекта прямо из консоли: оператор с правом на создание вводит одно название, получает чистый проект со всеми правами в нём и продолжает работу уже в этом проекте.

## Requirements

### Requirement: Действие создания проекта в консоли

Консоль SHALL показывать действие создания проекта в модальном окне текущего проекта, открываемом из верхней панели. Отдельной кнопки создания в верхней панели MUST NOT быть. Действие MUST быть видно только оператору, которому платформа разрешает создавать проекты. Остальным операторам действие MUST NOT показываться, а окно проекта MUST оставаться доступным для просмотра и переключения.

#### Scenario: Действие видно уполномоченному оператору

- **WHEN** оператор с правом создавать проекты открывает окно проекта
- **THEN** в окне доступно действие создания нового проекта

#### Scenario: Действие скрыто

- **WHEN** оператор без права создавать проекты открывает окно проекта
- **THEN** действие создания проекта не показывается, а список проектов и события остаются видны

### Requirement: Проект создаётся по одному названию

Диалог создания SHALL требовать только название проекта. Ключ проекта SHALL выводиться платформой из названия и MUST быть уникальным среди существующих проектов; при совпадении платформа SHALL получить другой уникальный ключ, не спрашивая оператора. Пустое название SHALL отклоняться до отправки. Отказ платформы SHALL показываться понятным сообщением, а диалог MUST оставаться открытым с введённым названием.

#### Scenario: Создание по названию

- **WHEN** оператор вводит название и подтверждает создание
- **THEN** проект создаётся, его ключ получен платформой из названия

#### Scenario: Название уже занято

- **WHEN** оператор создаёт проект с названием, совпадающим с существующим
- **THEN** проект создаётся с другим уникальным ключом, ошибки оператор не видит

#### Scenario: Пустое название

- **WHEN** оператор подтверждает создание с пустым названием
- **THEN** консоль показывает ошибку поля и не отправляет запрос

#### Scenario: Платформа отклонила создание

- **WHEN** платформа отвечает ошибкой на создание проекта
- **THEN** оператор видит понятное сообщение, диалог остаётся открытым, введённое название сохранено

### Requirement: Новый проект чист и полностью доступен создателю

Созданный проект MUST NOT содержать контента: ни категорий, ни постов, ни страниц, ни исследований, ни медиа. Создатель MUST получить в нём роль владельца со всеми правами проекта и MUST иметь доступ ко всем разделам консоли, доступным владельцу. Сервисы проекта SHALL включаться по умолчанию платформы. Предустановленные инструкции платформы SHALL быть доступны в новом проекте без дополнительных действий.

#### Scenario: Проект пуст

- **WHEN** оператор открывает разделы только что созданного проекта
- **THEN** списки контента пусты и предлагают создать первую запись

#### Scenario: Создатель — владелец

- **WHEN** создатель открывает права и разделы нового проекта
- **THEN** он имеет роль владельца и доступ ко всем разделам консоли этого проекта

#### Scenario: Генерация работает сразу

- **WHEN** в новом проекте запускается генерация, для которой нет своей инструкции
- **THEN** применяется предустановленная инструкция платформы

### Requirement: Консоль переключается на созданный проект

После успешного создания консоль SHALL сделать новый проект текущим и обновить разделы под него без перезагрузки страницы вручную. Ранее выбранный проект MUST оставаться доступным для возврата.

#### Scenario: Переход в новый проект

- **WHEN** создание проекта завершилось успешно
- **THEN** консоль показывает данные нового проекта, разделы относятся к нему

#### Scenario: Возврат к прежнему проекту

- **WHEN** оператор после создания возвращается к прежнему проекту
- **THEN** разделы снова показывают данные прежнего проекта
