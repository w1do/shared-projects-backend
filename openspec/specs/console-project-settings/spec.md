# console-project-settings Specification

## Purpose
Раздел «Основные» в настройках консоли: что оператор видит и правит в текущем проекте — идентификатор, название, описание, параметры сайта и запуск сборки проекта по AI, откуда значения читаются и куда сохраняются. Раздел описывает проект платформы, а не витрину магазина из шаблона вёрстки.

## Requirements

### Requirement: Раздел «Основные» описывает проект

Вкладка «Основные» в настройках SHALL называться «Главные настройки сайта» и сопровождаться описанием «Настройки сайта, управление данными». Раздел SHALL содержать поля проекта: название сайта, описание сайта, тип проекта, часовой пояс, поддерживаемые валюты и валюту по умолчанию, язык по умолчанию. Поля витрины магазина — единица веса, email поддержки, телефон, адрес витрины — MUST NOT показываться.

#### Scenario: Заголовок и состав раздела

- **WHEN** оператор открывает настройки на вкладке «Основные»
- **THEN** он видит заголовок «Главные настройки сайта», описание «Настройки сайта, управление данными» и поля проекта

#### Scenario: Полей магазина нет

- **WHEN** оператор открывает вкладку «Основные»
- **THEN** поля единицы веса, email поддержки, телефона и адреса витрины не показываются

### Requirement: Идентификатор, название и описание проекта в разделе

Раздел SHALL показывать идентификатор, название и описание текущего проекта. Идентификатор проекта SHALL выводиться в начале раздела, над полями настроек, и быть доступен для копирования одним действием. Данные MUST приходить из платформы, а не быть зашитыми в вёрстку. Главная страница консоли MUST NOT показывать карточку проекта.

#### Scenario: Оператор видит проект

- **WHEN** оператор открывает раздел «Основные» настроек
- **THEN** он видит идентификатор проекта сверху раздела, а также его название и описание

#### Scenario: Описание не заполнено

- **WHEN** у проекта нет описания
- **THEN** раздел показывает подсказку о незаполненном описании и предлагает собрать проект по AI

#### Scenario: Смена проекта

- **WHEN** оператор переключается на другой проект
- **THEN** раздел показывает данные выбранного проекта

#### Scenario: Дашборд без карточки

- **WHEN** оператор открывает главную страницу консоли
- **THEN** карточка проекта на ней отсутствует

### Requirement: Значения раздела приходят из платформы и сохраняются в неё

Значения полей раздела SHALL читаться из платформы и записываться в неё при сохранении: название и описание сайта — поля текущего проекта, тип проекта, часовой пояс, валюты и язык по умолчанию — настройки этого проекта. Название сайта, показанное в разделе, MUST совпадать с названием проекта в переключателе проектов; отдельного второго названия MUST NOT существовать. Сохранение MUST отправлять запрос в платформу: имитация успеха без обращения к ней MUST NOT использоваться. Успешное сохранение SHALL подтверждаться сообщением, отказ платформы SHALL показываться понятным сообщением, а значения полей при отказе MUST оставаться введёнными оператором. Правка полей раздела SHALL быть доступна оператору с правом управления проектом; без этого права элементы правки MUST NOT показываться.

#### Scenario: Сохранение переживает перезагрузку

- **WHEN** оператор меняет значения и сохраняет раздел, затем перезагружает консоль
- **THEN** поля показывают сохранённые значения

#### Scenario: Правка описания

- **WHEN** оператор изменяет описание проекта и сохраняет
- **THEN** новое описание отображается и сохраняется после перезагрузки

#### Scenario: Переименование видно в переключателе проектов

- **WHEN** оператор меняет название сайта и сохраняет раздел
- **THEN** новое название показывается в переключателе проектов консоли

#### Scenario: Отказ платформы

- **WHEN** платформа отклоняет сохранение настроек
- **THEN** оператор видит понятное сообщение, введённые значения остаются в форме

#### Scenario: Нет права управления

- **WHEN** раздел открывает оператор без права управления проектом
- **THEN** он видит данные проекта, но не видит элементов правки

### Requirement: Выбор из допустимых значений

Тип проекта, часовой пояс, валюты и язык по умолчанию SHALL выбираться из списков, а не вводиться текстом. Список часовых поясов SHALL содержать российские часовые пояса. Список валют SHALL содержать рубль и доллар США. Список языков SHALL содержать языки, привязанные к текущему проекту; язык по умолчанию SHALL выбираться из них и MUST быть виден в этом же разделе.

#### Scenario: Часовые пояса России

- **WHEN** оператор открывает список часовых поясов
- **THEN** ему предлагаются российские часовые пояса

#### Scenario: Валюты проекта

- **WHEN** оператор открывает список валют
- **THEN** ему предлагаются рубль и доллар США

#### Scenario: Языки проекта

- **WHEN** оператор открывает выбор языка по умолчанию
- **THEN** ему предлагаются языки, привязанные к текущему проекту, а текущий язык отмечен

### Requirement: Запуск сборки проекта по AI

Раздел «Основные» настроек SHALL содержать действие «Собрать проект по AI». Действие SHALL запрашивать тематику проекта и запускать сборку. Доступность действия MUST NOT зависеть от включённости сервиса аналитики. Пока сборка идёт, консоль SHALL показывать её ход и MUST NOT позволять запустить вторую сборку. По завершении консоль SHALL показать результат и обновить данные проекта в разделе.

#### Scenario: Запуск сборки

- **WHEN** оператор нажимает «Собрать проект по AI» и указывает тематику
- **THEN** консоль показывает, что сборка идёт, и кнопка повторного запуска недоступна

#### Scenario: Сборка завершилась

- **WHEN** сборка завершилась успешно
- **THEN** раздел показывает заполненное описание проекта, а оператору сообщается, сколько категорий создано

#### Scenario: Сборка не удалась

- **WHEN** сборка завершилась ошибкой
- **THEN** оператор видит сообщение об ошибке и может запустить сборку повторно

#### Scenario: Аналитика выключена

- **WHEN** сервис аналитики выключен для проекта
- **THEN** действие «Собрать проект по AI» остаётся доступным в разделе «Основные»

#### Scenario: Действие скрыто без права

- **WHEN** раздел открывает оператор без права управления проектом
- **THEN** действие «Собрать проект по AI» не показывается
