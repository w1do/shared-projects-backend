# console-seo-ui Specification

## Purpose
Раздел SEO в панели управления: единая таблица SEO-полей по всем сущностям контента проекта с правкой записи и пересбором полей по AI.

## Requirements

### Requirement: Раздел SEO в группе «Контент»

Панель SHALL предоставлять раздел «SEO» пунктом меню в группе «Контент». Раздел SHALL быть объявлен за сервисом `content` и правом `content.seo.manage`: пункт SHALL отображаться только при включённом сервисе и наличии права, прямой переход по адресу без доступа SHALL вести на страницу отказа. Тексты SHALL определяться ключами `console.*` с русскими значениями по умолчанию.

#### Scenario: Раздел виден при включённом сервисе и праве

- **WHEN** сервис `content` включён для проекта и у оператора есть право `content.seo.manage`
- **THEN** пункт «SEO» присутствует в группе «Контент» и раздел открывается

#### Scenario: Сервис контента выключен

- **WHEN** администратор выключает сервис `content`
- **THEN** пункт «SEO» исчезает из меню без повторного входа, а прямой адрес ведёт на страницу отказа
### Requirement: Таблица SEO по сущностям контента

Раздел SHALL показывать SEO-записи текущего проекта таблицей с постраничной навигацией: тип сущности, её название и все SEO-поля платформы — title, description, keywords, canonical, robots, og:title, og:description, og:image, twitter card, JSON-LD. Таблица SHALL позволять отобрать записи по типу сущности (пост, категория, страница) и отсортировать их по типу, названию сущности и дате изменения. Сущность без заполненного SEO SHALL присутствовать в таблице с пустыми полями и быть отличима от заполненной.

#### Scenario: Отбор по типу сущности

- **WHEN** оператор отбирает записи по типу «категория»
- **THEN** в таблице остаются только SEO-записи категорий

#### Scenario: Сортировка

- **WHEN** оператор сортирует таблицу по названию сущности
- **THEN** записи выстраиваются в выбранном порядке, а отбор по типу сохраняется

#### Scenario: Незаполненное SEO видно

- **WHEN** у поста нет заполненного SEO
- **THEN** пост присутствует в таблице с пустыми полями и помечен как незаполненный
### Requirement: Правка SEO-записи из раздела

Оператор SHALL иметь возможность изменить SEO-поля записи прямо из раздела. Сохранённые значения MUST быть видны после перезагрузки страницы. Отказ платформы, включая синтаксически неверный JSON-LD, SHALL показываться оператору сообщением на русском языке, а сохранённые ранее значения MUST NOT затираться.

#### Scenario: Правка полей

- **WHEN** оператор изменяет title и description SEO-записи и сохраняет
- **THEN** новые значения видны в таблице и сохраняются после перезагрузки

#### Scenario: Неверный JSON-LD

- **WHEN** оператор сохраняет синтаксически неверный JSON-LD
- **THEN** он видит сообщение об ошибке, а прежние значения записи остаются неизменными
### Requirement: Пересбор SEO-полей по AI

Раздел SHALL предоставлять запуск пересбора SEO-полей по AI для выбранных строк таблицы и для всех записей проекта. Запуск SHALL быть доступен оператору с правом `content.seo.manage`. Пока пересбор идёт, консоль SHALL показывать его ход и MUST NOT позволять запустить второй пересбор в этом же проекте. По завершении консоль SHALL показать результат и перечитать таблицу. Ход задачи SHALL храниться в платформе: перезагрузка страницы MUST NOT терять прогресс.

#### Scenario: Пересбор выбранных строк

- **WHEN** оператор выбирает несколько записей и запускает пересбор по AI
- **THEN** консоль показывает, что задача принята и выполняется, а по завершении таблица показывает новые значения выбранных записей

#### Scenario: Пересбор всех записей

- **WHEN** оператор запускает пересбор по AI для всех записей проекта
- **THEN** задача принимается один раз, повторный запуск недоступен до её завершения

#### Scenario: Перезагрузка страницы во время пересбора

- **WHEN** оператор перезагружает страницу, пока пересбор идёт
- **THEN** раздел снова показывает ход выполняющейся задачи

#### Scenario: Пересбор не удался

- **WHEN** задача пересбора завершилась ошибкой
- **THEN** оператор видит причину на русском языке и может запустить пересбор повторно
