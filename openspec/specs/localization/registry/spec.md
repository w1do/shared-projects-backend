# localization/registry Specification

## Purpose
Единый реестр локализаций: хранение ключей/значений по проекту, регистрация из сервисов и синхронизация с вёрсткой.

## Requirements

### Requirement: Регистрация ключей локализации сервисами
Система SHALL предоставлять API регистрации ключей локализации на этапе загрузки пакетов, чтобы каждый сервис мог объявить свои ключи и значения по умолчанию.

#### Scenario: Регистрация ключей при инициализации
- **WHEN** сервис вызывает реестр локализации для регистрации своих ключей
- **THEN** ключи и значения по умолчанию становятся доступны для чтения и синхронизации

### Requirement: Команда синхронизации локализаций
Система SHALL предоставлять команду `php artisan localize:sync`, которая синхронизирует зарегистрированные ключи с таблицей `localization` и помечает отсутствующие/новые.

#### Scenario: Успешная синхронизация
- **WHEN** запускается команда `localize:sync`
- **THEN** в таблицу `localization` добавляются недостающие ключи, обновляются изменённые значения по умолчанию, формируется отчёт о добавленных/обновлённых

### Requirement: Чтение локализаций в рантайме
Система SHALL предоставлять контракт для получения значения локализации по ключу и языку, с fallback на значение по умолчанию.

#### Scenario: Fallback на значение по умолчанию
- **WHEN** значение на выбранном языке отсутствует
- **THEN** возвращается значение по умолчанию
