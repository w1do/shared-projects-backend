# Города и регионы (`city:sync`, раздел «Города»)

Справочник регионов и городов России — общий на платформу: `regions` и `cities`
не принадлежат проекту, потому что Казань одинакова во всех проектах. Проектное
состояние живёт в `project_cities`: строка есть — город у проекта включён.

## Наполнение справочника

```bash
php artisan city:sync                          # поставляемая копия набора
php artisan city:sync /path/to/russia-cities.json
php artisan city:sync https://raw.githubusercontent.com/arbaev/russia-cities/master/russia-cities.json
```

Копия исходного набора [arbaev/russia-cities](https://github.com/arbaev/russia-cities)
лежит в `packages/cms/content/resources/geo/`, поэтому прогон не зависит от сети.
Команда только добавляет и обновляет: город с SEO и включённостью проектов не
удаляется молча, а исчезнувшая из источника запись попадает в сводку прогона.

В бутстрапе команда стоит после публикации манифестов —
`CITY_SYNC=1` в `infra/docker/entrypoint.sh` и шаг `sync cities directory`
в `tools/smoke.sh`. Без неё раздел «Города» пуст.

## Состав городов проекта

При первом обращении проекта к разделу платформа включает 10 крупнейших по
населению. Дальше состав меняет только оператор: переключателем в строке,
действием «включить все» или возвратом к стартовому набору. Стартовый набор
применяется один раз — выключённый город остаётся строкой со снятым флагом.

Размер стартового набора — `CONTENT_CITY_STARTER_SIZE` (по умолчанию 10),
источник по умолчанию — `CONTENT_CITY_DIRECTORY`.

## SEO города и адаптация под тематику

SEO города — та же полиморфная модель, что у постов, страниц и категорий, с
типом `city`. Запись принадлежит паре «проект + город»: один Новосибирск у двух
проектов описан по-разному. В каталог `/content/seo` города не попадают — их
тысяча, и правятся они в своём разделе.

Кнопка «AI: адаптировать под проект» ставит фоновую задачу вида
`city_seo_adaptation`: она обходит включённые города пачками по 25 и заполняет
текстовые SEO-поля по инструкции категории «SEO города» с подстановкой тематики.
Адреса, robots, og:image и JSON-LD остаются такими, какими их оставил оператор.
Отказ модели по городу не затирает его SEO и не останавливает задачу.

## Замеры на полном справочнике

Dev-стенд, справочник 83 региона / 1102 города, проект `demo`:

| Операция | Значение |
| --- | --- |
| `city:sync` на пустом справочнике | ~2.4 c (83 региона, 1102 города) |
| повторный `city:sync` | ~0.4 c, нулевые изменения |
| список городов, страница 100 | ~8 мс |
| поиск по названию | ~9 мс |
| список регионов | ~6 мс |
| «включить все» (1102 строки включённости) | ~32 мс, один запрос |
| «вернуться к 10 крупнейшим» | ~13 мс, один запрос |
| AI-адаптация 10 включённых городов | ~40 c, ход задачи `10/10` |
